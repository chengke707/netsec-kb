# TCP SYN 泛洪攻击

**课本原文（P31）**
> 攻击者利用TCP中的3次握手过程中存在的漏洞，向目标主机发送大量伪造的TCP SYN连接请求……攻击者并不会回复TCP ACK包，而是会忽略目标主机发来的TCP SYN+ACK包并持续发送TCP SYN连接请求，从而导致目标主机长时间等待TCP连接的建立，占用大量资源，最终导致目标主机无法正常工作。

**要点**
- 属于[[拒绝服务]]（DoS）攻击，利用 3 次握手漏洞。
- 流程：伪造大量 SYN → 目标回 SYN+ACK → 攻击者不回 ACK → 连接半开占用资源，最终拒绝正常服务。
- 防御：防火墙过滤、**SYN Cookie**（不存储连接信息即可正确处理连接请求）、限制 TCP 连接数。
- 同族攻击：见[[TCP安全]]（SYN 扫描、FIN 扫描、LAND、中间人攻击）。
