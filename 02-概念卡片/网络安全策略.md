# 网络安全策略

**课本原文（P4）**
> 网络安全最重要的任务就是制定网络安全策略，安全策略决定了一个组织机构怎样来保护自己。一般来说，策略包括两部分内容：总体的策略和具体的规则。

**要点**
- 总体策略 = 战略指导方针（由高层管理者主持制定）；具体规则 = 允许/禁止什么活动。
- 内容 4 方面：用户安全责任、系统管理员安全责任、正确利用网络资源、检测到安全问题时的对策。
- 实施：要真正执行 + 分配责任到部门 + 投入人力物力监督；不能只是"给审查者看的纸"。
- 设计核心原则：准许访问除明确拒绝以外 / 拒绝访问除明确准许以外。
- 实现网络安全：技术 + 严格管理 + 法律约束 + 安全教育。
