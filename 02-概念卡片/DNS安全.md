# DNS安全

**课本原文（P34）**
> DNS是一种用于TCP/IP应用程序的分布式数据库，它提供主机名和IP地址之间的转换信息。通常，网络用户通过UDP与DNS服务器进行通信，而服务器在特定的53端口监听。

**要点**
- 不安全因素：UDP 本身不安全、树形结构易**单点故障**、BIND 软件漏洞（缓冲区溢出/拒绝服务）。
- **4 类攻击**：DDoS、缓冲区投毒（缓存中存入错误数据，客户被重定向到错误 IP，还可能扩散中毒）、区域信息泄露（泄露网络拓扑/子网结构）、域名劫持（窃取账号密码取得域名管理权）。
- 防范：包过滤（端口 53 / 合法 IP / 流量限制，正常请求 ≤512 字节）、防火墙保护（Split DNS 内外分离）、网络拓扑限制（避免同一子网/链路/路由器/自治域/物理位置）、DDoS 防范（IDS、多数据中心冗余、防火墙限流、流量分析）。
