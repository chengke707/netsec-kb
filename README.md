## 目录结构
| 文件夹 | 内容 |
|---|---|
| `01-章节笔记/` | 每章完整笔记（含课本原文引用） |
| `02-概念卡片/` | 每个概念一个卡片 → Obsidian 图谱的节点 |

## 三种打开方式
1. **Obsidian（推荐，图谱体验最佳）**：用 Obsidian 打开本文件夹，点开「图谱视图」即可看到概念关系网。手机/平板装 Obsidian App，配合坚果云 / OneDrive / iCloud 同步同一文件夹即可随时看。
2. **浏览器**：任何设备直接打开 `图谱.html`，无需安装任何软件，离线可用。
3. **直接看笔记**：`01-章节笔记/` 与 `02-概念卡片/` 的 md 文件即完整内容。

## 提问与疑问记录规则
- 你随时提问；我讲解后会把**你的疑问**整理成一条新记录写入 `03-疑问集/`（命名 `Q001-标题.md`）。
- 每条疑问包含：你的问题 → 我的讲解 → 课本原文引用 → 关联概念卡片 → 掌握程度。
- 每次新增后我会同步更新 `图谱.html`，你的疑问会自动变成图谱里的橙色节点。
