## 一、必背定义（原文背诵）
1. **网络安全（P2）**：网络安全是指网络系统的硬件、软件及其中的数据受到保护，不因偶然的或者恶意的原因而遭到破坏、更改或窃取，系统连续、可靠、正常地运行，网络服务不中断。
2. **保密性（P2）**：信息不泄露给非授权的用户、实体或过程。
3. **完整性（P2）**：数据未经授权不能被改变，信息在存储或传输过程中不被修改、破坏和丢失。
4. **可用性（P2）**：可被授权实体访问并按需求使用。
5. **可控性（P2）**：能够对信息的传播及内容进行控制。
6. **非授权访问（P2）**：没有预先经过同意就使用网络或计算机资源；避开访问控制、越权访问信息。
7. **信息泄露（P2）**：将有价值的或高度机密的信息暴露给无权访问该信息的人的所有问题。
8. **拒绝服务（P2）**：故意攻击网络协议缺陷，或耗尽被攻击对象资源，使其无法提供正常服务。
9. **系统漏洞（P8）**：应用软件或操作系统在逻辑设计上的缺陷或在编写时产生的错误。
10. **信息包筛选（P14）**：常驻于路由器或专用主计算机系统的数据库规则，审查网络通信并决定是否允许通过。
11. **网络安全风险管理（P20）**：识别、评估和控制网络系统安全风险的总过程，贯穿整个系统开发生命周期。
12. **网络安全风险评估（P22）**：对网络自身脆弱性状况、网络安全事件发生的可能性及可能造成的影响进行评估。

## 三、易混对照（最爱考）
| 易混项 | 区别 |
|---|---|
| 保密性 vs 完整性 vs 可用性 | 保密 = 不被看；完整 = 不被改；可用 = 能用 |
| 身份识别 vs 身份认证 | 识别 = 用户出示证明；认证 = 系统核查证明 |
| 信息包筛选 vs 应用中继器 | 包筛 = 规则放行/拦截（快、透明、无状态）；中继器 = 代理服务（隐藏拓扑、对用户不透明） |
| S-HTTP vs SSL | S-HTTP 按**单个文件**做私人/签字；SSL 按**进程间数据通道**监管私有/已认证 |
| PEM vs PGP | PEM 依赖分层 PKI（IPRA→PCA→CA）；PGP 分布式信任（用户自己决定信任谁） |
| 物理分段 vs 逻辑分段 | 物理层/数据链路层隔离；网络层（IP 子网）隔离 |
| 冷备份 vs 热备份 | 冷备份停机备份；热备份实时性好、保证数据完整连续性，广泛采用 |
