# 第1章 习题 · 简答背诵版（课本 P37）

> 课本最后一页这 10 题就是考试原型：题型全部为**简答题**，背诵量很大。
> 每题按「背诵答案 → 关键词 → 关联」组织，先背原文，再记关键词。

## 1. 网络安全的含义是什么？
**背诵答案**
- 定义（背原文）：网络安全是指网络系统的硬件、软件及其中的数据受到保护，不因偶然的或者恶意的原因而遭到破坏、更改或窃取，系统连续、可靠、正常地运行，网络服务不中断。
- 本质：网络上的**信息安全**。
- 补充：计算机网络安全 = 通过计算机、网络、密码技术和信息安全技术，保护公用通信网络中传输、交换和存储的信息的**机密性、完整性和真实性**，并对信息的传播及内容进行控制。
**关键词**：硬件软件数据受保护 → 不遭破坏/更改/窃取 → 连续可靠正常运行 → 服务不中断
**关联**：[[网络安全]]

## 2. 网络安全有哪些特征？
**背诵答案**
① 保密性：信息不泄露给非授权的用户、实体或过程。（→ 不被窃听、不被非法使用）
② 完整性：数据未经授权不能被改变，存储/传输中不被修改、破坏、丢失。（→ 不被拦截、篡改）
③ 可用性：可被授权实体访问并按需求使用。（→ 正常提供服务）
④ 可控性：能够对信息的传播及内容进行控制。
**关键词**：四性 = 保密、完整、可用、可控；记法：**不被看、不被改、能用、能管**
**关联**：[[保密性]] · [[完整性]] · [[可用性]] · [[可控性]]

## 3. 什么是网络安全的最大威胁？
**背诵答案**
- 计算机网络安全受到的威胁主要有：**"黑客"的攻击、计算机病毒和拒绝服务攻击**。
- 补充（6 类威胁形式）：非授权访问、假冒合法用户、破坏数据完整性、干扰系统正常运行、病毒破坏、通信线路被窃听。
**关键词**：黑客 + 病毒 + 拒绝服务
**关联**：[[拒绝服务]] · [[程序攻击]] · [[系统漏洞]]

## 4. 网络安全主要有哪些关键技术？
**背诵答案**
7 项：① 主机安全技术 ② 身份认证技术 ③ 访问控制技术 ④ 密码技术 ⑤ 防火墙技术 ⑥ 安全审计技术 ⑦ 安全管理技术。
**关键词**：主机、认证、访问控制、密码、防火墙、审计、管理（记 7 个词即可）
**关联**：[[防火墙]] · [[认证]] · [[加密]]

## 5. 如何实施网络安全的安全策略？
**背诵答案**
- 策略构成：**总体策略**（战略方针，管理者主持制定）+ **具体规则**（什么活动被允许/禁止）。
- 内容 4 方面：① 网络用户的安全责任 ② 系统管理员的安全责任 ③ 正确利用网络资源 ④ 检测到安全问题时的对策。
- 实施要点：策略必须**真正执行**（不是给审查者看的纸）；分配责任到部门并投入人力物力监督；技术人员与管理人员共同参与。
- 三保障：先进技术 + 严格的安全管理 + 法律约束和安全教育。
**关键词**：总体+具体；4 内容；真执行；技术/管理/法律/教育
**关联**：[[网络安全策略]]

## 6. 如何理解协议安全的脆弱性？
**背诵答案**
- 根本原因：TCP/IP 设计初期**过分强调开放性和便利性，没有仔细考虑其安全性**（P25）。
- 具体表现：
  ① 数据链路层：CSMA/CD 共享信道 → 可在线窃听；
  ② 网络层：ICMP（ping）可被泛洪淹没服务器；
  ③ IP 层：源 IP 地址可伪造 → IP 欺骗；
  ④ UDP 面向无连接，本身不安全；
  ⑤ 部分服务天生不安全：BSD TCP/IP 的 r 命令（rlogin、rsh）、Web Includes、CGI 漏洞。
- 实例：1988 年 Robert Morris 的 GUESS 口令猜测程序（蠕虫），几乎每年给互联网造成上亿美元损失（P7）。
**关键词**：开放便利 → 忽视安全；共享信道 / ICMP / IP欺骗 / UDP / r 命令
**关联**：[[系统漏洞]] · [[TCP安全]] · [[DNS安全]]

## 7. 数据库管理系统有哪些不安全因素？
**背诵答案**
- DBMS 对数据库的管理建立在**分级管理**概念上，安全性难以保证；
- DBMS 的安全**必须与操作系统的安全配套**，这是先天的不足之处（P7）。
**关键词**：分级管理 + 必须与 OS 配套
**关联**：[[系统漏洞]]

## 8. 介绍网络信息安全模型。
**背诵答案**
金字塔 5 层（**自底向上**）：
1. 政策、法律法规——安全的基石，建立安全管理标准；
2. 增强的用户认证——技术措施的首道防线，目的是提供访问控制（三种方法：用户持有的凭证 / 用户知道的信息 / 用户独有的特征）；
3. 授权——为特许用户提供合适访问权限，并监控活动使其不越权；
4. 加密——满足认证、一致性、隐秘性、不可抵赖；
5. 审计与监控——系统安全的最后一道防线，含数据备份（问题再现、责任追查、数据恢复）。
> 5 个部分相辅相成、缺一不可，底层是保障上层的基础。
**关键词**：法规 → 认证 → 授权 → 加密 → 审计（自下而上）
**关联**：[[网络信息安全模型]] · [[认证]] · [[加密]]

## 9. 对互联网进行安全管理需要哪些措施？
**背诵答案**
- 遵循保密基本原则：① 根据面临的安全问题决定安全策略；② 新技术的产生及时补充相应策略；③ 内网 Intranet 与 Internet 之间设置防火墙（IP 地址分配用**双轨制**）。
- 完善管理功能：建立完善法律法规；加强审计工作（安全信息记录 → 跟踪 → 分析报告）；建立规章制度（人员许可证制度、操作方式规范、安全管理责任制）。
- 加大安全技术开发力度：加密、鉴别、密钥管理、访问控制、数据完整性、安全审计等标准化研究。
**关键词**：原则 3 条 + 管理 3 招 + 技术开发
**关联**：[[网络安全策略]] · [[防火墙]]

## 10. 简述信息包筛选的工作原理。
**背诵答案**
- 信息包筛选是**常驻于路由器或专用主计算机系统（通常在两个网络之间）的数据库规则**（P14）。
- 它逐包审查网络通信，根据**筛选规则**决定是否允许信息包通过；规则是一组逻辑规则，如"上午 9 时到下午 5 时，允许主机 A 和 B 之间的全部 Telnet 信息通过"。
- 传统工具能获得的信息限于：源 IP 地址、目的 IP 地址、信息包类型、目的端口（无法检查源端口）。
- 可在进入/离开路由器的线路上筛选；在进入线路上筛选可防止**地址欺骗**。
- 局限：不能保留已通过信息包的详细信息（无状态）；规则可能互相矛盾或次序歧义。
**关键词**：常驻规则库 → 逐包审查 → 按规则放行/拦截 → 防地址欺骗 → 无状态
**关联**：[[信息包筛选]] · [[防火墙]] · [[应用中继器]]
